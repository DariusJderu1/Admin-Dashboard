# Admin Dashboard

A static administrative dashboard layout built with HTML and CSS. The primary focus of this project is using CSS Grid and Flexbox to structure and align the user interface.

**Live Demo:** [https://dariusjderu1.github.io/Admin-Dashboard/](https://dariusjderu1.github.io/Admin-Dashboard/)

## Technologies Used

* **HTML5:** Semantic structuring of the dashboard sections (`<header>`, `<aside>`, `<main>`, `<section>`).
* **CSS3:** * **CSS Grid:** Used for the main page layout (sidebar and content areas) and the grid of project cards.
  * **Flexbox:** Used for aligning items within individual components (header elements, navigation links, card content).

## Features

* **Sidebar Navigation:** A sticky sidebar with navigation links and icons.
* **Header:** Includes a search bar mockup, profile information, and action buttons.
* **Project Cards:** A grid layout displaying content cards that automatically wrap based on screen width.
* **Information Panels:** Additional sidebar sections for announcements and trending users.
